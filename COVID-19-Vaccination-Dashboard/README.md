## Overview

This project presents an interactive Tableau dashboard that analyzes global COVID-19 vaccination trends, vaccination coverage, and progress across countries and regions.

## Tools Used

* Tableau Public

## Key Features

* Global vaccination overview
* Vaccination trend analysis
* Country comparison
* Interactive filters
* KPI monitoring

## Skills Demonstrated

* Data Analysis
* Dashboard Development
* KPI Reporting
* Data Storytelling
* Data Visualization
