MetroCar SQL Data Analysis Project

Project Overview
This project analyzes MetroCar ride-hailing data using PostgreSQL and SQL to identify insights related to customer acquisition, ride operations, revenue generation, and customer satisfaction.

Tools Used
• PostgreSQL
• pgAdmin 4
• SQL

Business Questions
1. What percentage of app downloads convert into signups?
2. Where do users drop off in the customer funnel?
3. What factors contribute to cancellations?
4. When does peak demand occur?
5. What is the ride completion rate?
6. How do ratings reflect service quality?
7. What factors are associated with lower satisfaction?
8. What revenue trends exist over time?
9. Which platform generates the most downloads?
10. Which age group signs up the most?

Key Findings
• Signup conversion rate: 74.65%
• Cancellation rate: 41.65%
• Completion rate: 58.35%
• Average rating: 3.05/5
• iOS generated the highest downloads
• Users aged 35–44 represented the largest signup segment

Recommendations
• Improve driver availability
• Reduce cancellations
• Optimize ride matching
• Improve service consistency
• Encourage customer reviews

- ## Dataset

The analysis was performed using five MetroCar operational tables:

- app_downloads
- signups
- ride_requests
- transactions
- reviews

These tables capture the customer journey from app download through ride completion, payment transactions, and customer feedback.
