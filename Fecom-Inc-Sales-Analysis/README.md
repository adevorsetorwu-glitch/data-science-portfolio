# Fecom Inc. Sales Analysis Dashboard

## Project Overview

This project analyzes sales performance for Fecom Inc. using Microsoft Excel. The dashboard provides insights into revenue generation, order performance, customer demographics, product sales, seller performance, and regional sales trends.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design
- Data Cleaning

## Business Objectives

- Monitor overall revenue and sales performance.
- Identify top-performing product categories.
- Evaluate sales trends over time.
- Analyze regional sales distribution.
- Assess seller performance.
- Understand customer demographics.

## Key Performance Indicators (KPIs)

- Revenue: £389K
- Orders: 2,884
- Sellers: 735
- Average Order Value: £135

## Dashboard Insights

- Delivered orders accounted for the majority of transactions.
- Computers & Gaming generated the highest revenue among product categories.
- London recorded the highest regional sales activity.
- PrimeBuilders emerged as the top-performing salesperson.
- Revenue showed a generally upward trend over the reporting period.
