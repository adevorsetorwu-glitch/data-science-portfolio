# Just Store Sales Dashboard

## Overview

This Tableau dashboard provides an executive-level overview of sales performance for Just Store. The dashboard enables stakeholders to monitor key business metrics, evaluate regional performance, analyze category contributions, and track sales trends over time.

## Tools Used

* Tableau

## Project Objectives

* Monitor overall sales performance.
* Track profit and order trends.
* Compare sales performance across regions.
* Analyze category contributions to total sales.
* Evaluate monthly sales trends.
* Provide an interactive executive reporting solution.

## Key Features

* Executive KPI Dashboard
* Regional Sales Analysis
* Category Performance Analysis
* Profit Tracking
* Sales Trend Analysis
* Interactive Filters

## Skills Demonstrated

* Data Visualization
* Dashboard Development
* KPI Reporting
* Business Intelligence
* Executive Reporting
* Data Storytelling

## Dashboard Insights

* The West region generated the highest sales.
* Technology contributed the largest share of revenue.
* Sales showed fluctuations throughout the year with notable peaks in September and December.
* Category-level analysis revealed differences between sales and profit performance.
